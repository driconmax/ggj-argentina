# Cómo contribuir

Este sitio crece mediante cambios pequeños y revisables. Podés corregir una página desde su enlace de edición o trabajar con Git localmente.

## Antes de enviar información histórica

- Separá los datos confirmados de los recuerdos o versiones en discusión.
- Incluí fuentes públicas siempre que sea posible.
- Pedí permiso antes de publicar testimonios, imágenes o nombres que no sean ya públicos.
- No incluyas datos personales sensibles.

## Proceso

1. Elegí una plantilla o página existente.
2. Realizá el cambio en una rama propia.
3. Comprobá los enlaces y, si podés, ejecutá `mkdocs build --strict`.
4. Abrí un pull request explicando el origen de la información.

Para instrucciones más detalladas, consultá el archivo [CONTRIBUTING.md](https://github.com/driconmax/ggj-argentina/blob/main/CONTRIBUTING.md) del repositorio.
