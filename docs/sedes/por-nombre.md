# Sedes por nombre

Este índice listará alfabéticamente todas las sedes documentadas. Todavía no hay sedes verificadas para listar.

## Formato

```markdown
- [Nombre público de la sede](nombre-de-la-sede.md) — localidad, provincia
```

Cuando una sede haya cambiado de nombre, la ficha debe explicar el cambio y el índice puede incluir una referencia desde la denominación anterior.
