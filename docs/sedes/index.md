# Sedes

Este directorio reunirá las sedes argentinas documentadas por la comunidad. Una sede puede haber participado en una o varias ediciones; cada página debe indicar con claridad qué información está confirmada.

Podés recorrer el directorio de dos maneras:

- [Por provincia](por-provincia.md), para conocer la distribución territorial.
- [Por nombre](por-nombre.md), para encontrar rápidamente una sede.

Las páginas anuales de Historia tendrán sus propios índices con estos mismos dos criterios, limitados a las sedes que participaron en esa edición.

## Agregar una sede

Copiá la [plantilla de sede](plantilla-sede.md), completá los datos verificables y acompañá el cambio con fuentes. No publiques domicilios particulares, teléfonos personales ni otros datos sensibles.

Cada sede debe tener una única ficha dentro de `docs/sedes/`. Los índices solamente enlazan a esa ficha, de modo que las correcciones se hagan en un solo lugar.
