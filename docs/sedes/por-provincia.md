# Sedes por provincia

Este índice agrupará las sedes por provincia y, cuando resulte útil, por localidad. Todavía no hay sedes verificadas para listar.

## Formato

```markdown
## Provincia

### Localidad

- [Nombre de la sede](nombre-de-la-sede.md) — ediciones documentadas
```

Usá la denominación jurisdiccional correspondiente al período documentado y evitá inferir ubicaciones a partir del nombre de una institución.
