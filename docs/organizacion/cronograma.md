# Guía de fechas

Estos plazos son orientativos y se cuentan desde la apertura. Ajustalos a tu comunidad y consultá con [Global Game Jam](https://globalgamejam.org/) y la organización regional los requisitos y fechas oficiales de cada edición.

| Momento | Prioridades |
| --- | --- |
| 2–3 meses antes, o antes si es posible | Formar equipo, confirmar requisitos y reservar espacio; preparar presupuesto. |
| 6–8 semanas antes | Definir responsables, recursos, apoyos, inscripción y accesibilidad. |
| 3–4 semanas antes | Comunicar información práctica, revisar necesidades y preparar programa y turnos. |
| Última semana | Confirmar contactos, compras, equipos, señalización y alternativas. |
| Montaje | Preparar espacios, probar conexión y audiovisuales, repasar roles. |
| Durante | Dar bienvenida, acompañar y ayudar con la entrega de juegos. |
| Días posteriores | Devolver recursos, cerrar pagos, agradecer y compartir enlaces. |
| Semanas posteriores | Recoger comentarios, hacer retrospectiva y documentar aprendizajes. |

Si empezás más tarde, priorizá espacio y equipo, después inscripción y recursos, y finalmente los detalles del programa. Usá el [planificador](plantillas.md#planificador-de-tareas) para asignar responsables y fechas concretas.
