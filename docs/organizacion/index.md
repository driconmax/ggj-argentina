# Organización

Estas páginas reúnen criterios y listas de verificación para equipos que quieran organizar una sede. Son un punto de partida: deben adaptarse a las reglas vigentes de Global Game Jam, a la normativa local, al espacio y a las necesidades de cada comunidad.

## Principios

- Definir responsabilidades y canales de decisión desde el comienzo.
- Diseñar una experiencia accesible, inclusiva y segura.
- Comunicar con claridad horarios, reglas, recursos y límites del evento.
- Contar con consentimiento para publicar imágenes o datos de participantes.
- Documentar aprendizajes para futuras ediciones.
