# Licencia

## Estado actual

La licencia del proyecto todavía no fue elegida. Mientras no exista un archivo `LICENSE`, el contenido queda protegido por derecho de autor y no debe asumirse permiso general para copiarlo, modificarlo o redistribuirlo.

## Decisión recomendada

La comunidad debería resolver por separado:

1. **Contenido y documentación.** Una licencia Creative Commons puede ser apropiada. Por ejemplo, CC BY 4.0 permite reutilización con atribución; CC BY-SA 4.0 exige además compartir las adaptaciones bajo la misma licencia.
2. **Código y configuración.** Una licencia de software permisiva, como MIT, puede aplicarse a los archivos técnicos.

Estas opciones tienen efectos diferentes. Antes de adoptarlas, conviene acordar el objetivo, definir la atribución esperada y verificar que quienes ya contribuyeron acepten la decisión.

## Cómo formalizarla

- Registrar la decisión en un issue o discusión pública.
- Agregar el texto oficial en uno o más archivos `LICENSE` claramente identificados.
- Actualizar el README y esta página.
- Incorporar al proceso de contribución una aceptación explícita de la licencia elegida.
