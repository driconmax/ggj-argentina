# GGJ Argentina

Este sitio busca construir, de manera colaborativa, una memoria de las ediciones, sedes y aprendizajes de la comunidad de Global Game Jam en Argentina.

!!! note "Proyecto en construcción"
    La estructura inicial contiene plantillas y guías. La información histórica se incorporará a medida que pueda documentarse y revisarse colectivamente.

## Qué vas a encontrar

- **Historia:** registros de cada edición, con fuentes y testimonios cuando estén disponibles.
- **Sedes:** un directorio de sedes documentadas por la comunidad.
- **Organización:** aprendizajes y listas de verificación para organizar encuentros.
- **Recursos:** enlaces, materiales y herramientas que hayan resultado útiles.

## Sumate

Podés proponer correcciones o contenido nuevo desde GitHub. Antes de empezar, consultá la [guía para contribuir](contribuir.md).
