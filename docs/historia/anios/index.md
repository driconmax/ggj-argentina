# Ediciones por año

Cada edición tendrá un espacio propio con su historia, organización, participación argentina en la estructura internacional y sedes.

## Índice

Todavía no hay años publicados. Se incorporarán a medida que la comunidad pueda respaldar la información con fuentes o testimonios autorizados.

## Estructura de una edición

```text
historia/anios/AAAA/
├── index.md
├── sedes-por-provincia.md
└── sedes-por-nombre.md
```

Las dos listas de sedes son formas alternativas de acceder a las mismas fichas: no deben contener historias diferentes ni duplicar la información principal.

Para iniciar una edición, consultá la [plantilla anual](../plantilla-edicion.md).
